# TaskTap
The primary objective of TaskTap is to develop a web-based task and short-term job
management system that connects users within the same local area and provides a
convenient platform for posting, discovering, requesting, managing, and reviewing
small tasks.
The system's purpose is to facilitate access to short-term work available in the local
community, and to offer features for organized task management, accountability of
users and safer interactions between those who post tasks and those who assist
with them.
